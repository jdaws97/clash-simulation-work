  shared Angry/other targeting override always wins over partner movement. Otherwise

  Add exact relative partner-distance entry to shared range boundaries using the
  existing range_events helpers; stale sample-only merge arrival is not full support.

  keeps weighted living HP fraction and delays blocked midpoint release. No dead or

  Reserve exhaustion raises InputError. next_boundary and continuation report throws,

  handles actor fields; apply_status_receipt(receipt,recipient,time) handles spell
  runtime ledgers. Preserve cast IDs, original absolute expiry, target override and

  has_target_override(actor,time) asks the spell owner; no Angry field names are
