# Account-adapted recipe dependency map

The initial exact gaps were:

| Recipe | Initially unavailable selected content |
|---|---|
| Dragon: 8 | Action Figure; Baby Dragon; Frosty; Giant Arrow; Headhunter; Rocket Balloon; Super Wall Breaker; Totem |
| Root Rider: 12 | Action Figure; Apprentice Warden; Balloon; Earthquake Boots; Fireball; Giant Arrow; Headhunter; Log Launcher; Recall; Rocket Balloon; Super Barbarian; Totem |

Shared priority was Queen Action Figure/Giant Arrow → generated-summon ownership and shared ability; Headhunter → defending-hero acquisition/status; Rocket Balloon → boost/death lifecycle; Totem → paid cast, generated decoy and acquisition. Dragon additionally needed Baby Dragon sampling, Frosty children and one-use Super Wall Breaker. Root additionally needed Apprentice aura/following, Balloon death, Super Barbarian boost, Warden Fireball, King Earthquake Boots, Recall and rolling logs.

These are now conditional bindings under complete explicit parameters. Every new troop requires v27+ lifecycle scope; paid Totem/Recall require the v29 spell collection. Existing v29 contracts and unsupported checks remain in place. The consolidated change also incorporates complete TH17/18 scenario assembly and an explicit experimental Revenge Tower contract; see `HIGHER_TH_SCENARIOS.md`. It does not claim game calibration.

The principal fidelity blockers are **unverified seasonal/Giant Giant identity, synthetic Frostmite example quantities, missing Totem landing quantities, and unmeasured geometry/timing/selection contracts**. They are visible in policy and output provenance. The actual recommended inventories, entered levels and paid resources must be preserved when building comparative scenes. A supported benchmark army must not be described as the recommended recipe, and a partial/timed-out run supplies no full-battle outcome.

See `RECIPE_TROOP_CONTRACTS.md`, `RECIPE_EQUIPMENT_CONTRACTS.md`, `RECIPE_FROSTY_CONTRACT.md`, `RECIPE_SPELL_CONTRACTS.md`, and `CWL_PROFILE_DIAGNOSIS.md` for exact mechanisms, evidence and limits. Scenario results remain conditional on these contracts and on explicit deployment choices.
